GLOBAL REMIT BD DEMO — PWA PACKAGE

This is a demo-only app. It does not transfer real money or connect to bKash, Nagad, banks, or live exchange rates.

Files:
- index.html: repaired app
- manifest.webmanifest: install metadata
- sw.js: offline cache support
- icon.svg: app icon

To install on Android:
1. Host this folder on an HTTPS static host (for example, GitHub Pages).
2. Open the hosted website in Chrome on Android.
3. Tap Chrome menu (⋮) > Install app or Add to Home screen.
4. Confirm Install.

Opening index.html directly from Downloads may let you preview the app, but browser installation as a PWA requires HTTPS (or localhost).
